# SPC 统计过程控制与过程能力 Cpk

## 基本概念
- SPC（统计过程控制）通过对关键质量特性持续采样，监控过程是否稳定受控。
- 普通原因波动是过程固有；特殊原因波动导致失控，需识别并消除。

## 控制图
- 中心线 CL = 过程均值 X̄。
- 控制上限 UCL = X̄ + 3σ，控制下限 LCL = X̄ - 3σ。
- 点落在控制限之外，或出现连续同侧、趋势、周期性等异常排列，判定过程失控。

## 过程能力指数
- Cp = (USL - LSL) / (6σ)，反映过程潜在能力（不考虑中心偏移）。
- CPU = (USL - X̄) / (3σ)，CPL = (X̄ - LSL) / (3σ)。
- Cpk = min(CPU, CPL)，同时反映波动与中心偏移，是实际过程能力。

## 判读标准
- Cpk ≥ 1.67：过程能力充足。
- 1.33 ≤ Cpk < 1.67：能力可接受，持续监控。
- 1.00 ≤ Cpk < 1.33：能力不足，需改进。
- Cpk < 1.00：能力严重不足，必须采取措施。

## 系统使用
1. 在 QMS-SPC 页面录入特性值（可关联物料、工单）。
2. 查看控制图，系统返回数据点、均值、标准差、UCL/LCL。
3. 输入规格上下限（LSL/USL）计算 Cp/Cpk。
4. CTQ 关键特性建议优先纳入 SPC 监控。
