# 生产工单执行与报工作业流程

## 一、工单创建与下达
1. 计划员在 MES 创建生产工单（WorkOrder），选择成品物料、计划数量、计划开工/完工时间、工作中心。
2. 工单初始状态为 CREATED（已创建）。
3. 下达工单（RELEASED）：系统按 BOM 展开物料需求，向 WMS 发起领料波次（PickWave）。

## 二、拣货与线边交接
1. 仓库在 WMS 按领料波次执行拣货，系统按 FIFO（先进先出）推荐批次并进行条件库存扣减。
2. 拣货完成后，生产在 MES 执行“线边交接（收料）”。
3. 系统从 WMS 拉回实际拣货的批次与数量，写入投料记录（MaterialTxn）和产品谱系（子件批次）。
4. 交接后工单状态为 PICKED。

## 三、开工与报工
1. 工单开工（START），记录实际开工时间，状态变为 STARTED。
2. 生产过程中按工位/工序报工，录入合格数量、不良数量、报废数量及不良代码。
3. 首次报工后工单进入 RUNNING（生产中），系统累计完工、不良、报废数量。

## 四、完工与入库
1. 完成全部生产并已有合格报工后执行完工（COMPLETE）。
2. 系统生成成品批次号，回填产品谱系（成品批次 ← 子件批次）。
3. 系统通知 WMS 办理成品入库（成品库位、状态待检），同时通知 QMS 生成 OQC 成品出货检验任务。
4. OQC 合格后成品库存放行（QUALIFIED）方可出库；不合格则冻结并走 NCR/CAPA 流程。
5. 工单入库后状态为 STOCKED，最终可关闭（CLOSED）。

## 五、状态机
CREATED → RELEASED → PICKED → STARTED → RUNNING → STOCKED → CLOSED；
未完工工单可 CANCELLED（取消）。
